You shouldn’t need to know a title to find it.

Anime Akashic Records is a semantic retrieval engine over anime, manga, light novels, and visual novels. Describe what you half-remember — a plot, a key character dynamic, a studio, or just the vibe and mood you’re looking for. It searches across all four media and returns ranked matches, each paired with the exact passages confirming why the work fits.

What it does

Built for the moment when you remember a scene, not a name. Point it at a feeling and get back the works that fit — each one with the passage that matched.

Find it by feelNo title, no genre, no studio — just the vibe. “Something bittersweet and slow,” “a story for a rainy evening,” “cozy but a little lonely” — describe the feeling for that moment and it returns works to watch or read that match it.
Describe, don’t queryAsk in plain language. A plot, a mechanic, a studio, a mood — the catalogue understands all of them.
Four media, one indexAnime, manga, light novels and visual novels resolve to a single canonical work.
Built for fuzzy memoryHalf-remembered spellings, typos and romanisation drift still land on the right work.
Grounded, not guessedEvery result carries the passage that matched, so a recommendation can be checked, not just trusted.

API reference

JSON over HTTP. Two endpoints cover the whole catalogue. The API is hosted on RapidAPI, so one X-RapidAPI-Key header authenticates every call and the rate limit is whatever your plan allows.

Endpoints 
GET  /health   liveness check (no auth)
POST /search   ranked works, with the passages that matched

The search request

The demo sends exactly this shape. scope carries hard filters; every returned work carries the passage that matched.

POST /search 
{
  "question": "Time-travel visual novel with branching timelines",
  "limit": 8,
  "scope": { "types": ["VISUAL_NOVEL"] }
}

The response envelope

200 OK 
{
  "total_documents": 1,
  "results": [
    {
      "title": "Steins;Gate",
      "type": "visual_novel",
      "year": 2009,
      "score": 0.9412,
      "status": "finished",
      "chunks": [
        {
          "section": "Synopsis",
          "text": "Rintaro Okabe is a self-proclaimed mad scientist who accidentally discovers a way to send messages to the past, triggering unforeseen consequences across timelines."
        }
      ]
    }
  ]
}

Scope fields

Hard filters. scope rejects unknown fields rather than ignoring them, so a typo is an error you can see.

typesANIME · MANGA · LIGHT_NOVEL · VISUAL_NOVEL
genres / tags / themesFree-text filter lists.
studiosStudio names.
years / min_year / max_yearExact years or bounds.
min_scoreMinimum score threshold.
adultExplicit-content filter; the default excludes 18+.
staff_names / director_namesPeople filters.

Errors

401Missing or invalid key — {"detail":"missing or invalid API key"}
422A field failed validation (an unknown scope key, an empty question).

Get started

Four steps from a request to rendered results. The catalogue is served as a hosted API — subscribe on RapidAPI, take the base URL and key from your dashboard, and call it directly.

Hosted on RapidAPI Anime Akashic Records (AAR) API Subscribe on the listing to get your base URL and X-RapidAPI-Key, then call it directly. Plans and rate limits are shown there. Subscribe →
  1. 1

    Subscribe on RapidAPI

    Open the listing and pick a plan. Your dashboard shows the base URL and the X-RapidAPI-Key to send with every request; the origin server itself stays private.

  2. 2

    Send a request

    POST /search with a question and optional scope.

  3. 3

    Parse the envelope

    Read results[] with score, year and the matched passages.

  4. 4

    Render

    One ruled line per work, expanding to the passages that matched — exactly what the demo does.

Authentication

Every request carries your X-RapidAPI-Key header. The key is checked at the gateway, so the catalogue’s own origin is never exposed and never needs a second credential.
