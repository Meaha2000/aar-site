💡 Intended Scope & Relational Depth

Anime Akashic Records (AAR) is purpose-built for semantic retrieval, trope discovery, natural language query resolution, production metadata filtering, and grounded AI answer synthesis across 183,000+ canonical works and 389,000+ interconnected entities (characters, voice actors, directors, authors, composers, and work-to-work relationships). While deep production metadata is fully indexed and filterable in every payload, AAR is not designed as a real-time minute-by-minute episode airing tracker or personal watch-list manager.

Endpoints

Advanced Hybrid Retrieval

The primary discovery endpoint. Blends dense semantic vector embeddings with lexical keyword matching and neural reranking. Returns ranked works paired with confirming excerpts.

Request Parameters

questionstring (required) — Natural language question, scene description, trope, or production query.
limitinteger (optional, default: 8, max: 50) — Maximum number of works to return.
modestring (optional, default: "hybrid") — "hybrid" for balanced keywords & concepts; "semantic" for vector-only retrieval.
query_breakdownboolean (optional, default: true) — When true, the query passes through LLM query decomposition and refinement. When false, LLM breakdown is bypassed and the prompt is embedded directly as-is (significantly reducing latency).
nsfwboolean (optional, default: false) — Explicitly marks query as adult/NSFW, skipping LLM query refinement and proceeding directly to vector embedding.
includearray of strings (optional) — Expanded relational payloads to attach to each result: ["staff", "characters", "relations"].
scopeobject (optional) — Hard membership and relational filters (see Scope Filter Fields below).

Example Request

cURL 
curl -X POST "https://anime-akashic-records-aar-api.p.rapidapi.com/search" \
  -H "Content-Type: application/json" \
  -H "X-RapidAPI-Host: anime-akashic-records-aar-api.p.rapidapi.com" \
  -H "X-RapidAPI-Key: YOUR_RAPIDAPI_KEY" \
  -d '{
    "question": "Bounty hunters across the solar system with bebop jazz soundtrack",
    "limit": 5,
    "mode": "hybrid",
    "include": ["staff", "characters", "relations"],
    "scope": {
      "types": ["ANIME"],
      "director_names": ["Shinichirou Watanabe"],
      "composer_names": ["Yoko Kanno"]
    }
  }'

Question Answering

Conversational endpoint tailored for chatbots and AI agents. Synthesizes a grounded, factual natural-language prose answer derived strictly from retrieved canonical catalog records, production staff, and franchise relations.

Request Parameters

questionstring (required) — Natural language question regarding production, staff, franchise relations, or catalog metadata.
limitinteger (optional, default: 8) — Maximum reference works to retrieve for synthesis.
modestring (optional, default: "hybrid") — "hybrid" or "semantic" retrieval mode.
query_breakdownboolean (optional, default: true) — When true, uses LLM query refinement. When false, embeds the query directly as-is to minimize latency.
nsfwboolean (optional, default: false) — Explicitly marks query as adult/NSFW, skipping LLM query refinement and proceeding directly to vector embedding.
includearray of strings (optional) — Relational payloads to attach: ["staff", "characters", "relations"].

Scope Filter Fields

Hard filters supplied under the scope object. Unrecognized fields are strictly rejected with 422 so configuration mistakes are caught immediately. All staff and character filters support canonical romanizations and case-insensitive matching.

Production, Staff & Entity Filters

director_namesList of directors (e.g. ["Shinichirou Watanabe", "Akiyuki Shinbou", "Hideaki Anno"])
author_namesOriginal manga authors, light novel writers, or creators (e.g. ["Nisio Isin", "Kentarou Miura", "Naoki Urasawa"])
composer_namesMusic and soundtrack composers (e.g. ["Yoko Kanno", "Hiroyuki Sawano", "Yuki Kajiura", "Satoru Kousaki"])
voice_actor_namesVoice cast / seiyuu (e.g. ["Hiroshi Kamiya", "Chiwa Saitou", "Mamoru Miyano", "Megumi Hayashibara"])
staff_namesGeneral staff spanning all credited production roles (character designers, scriptwriters, sound directors)
character_namesCanonical characters appearing in the work (e.g. ["Shinobu Oshino", "Rintaro Okabe", "Spike Spiegel"])
titlesFilter directly by specific work titles (e.g. ["Cowboy Bebop", "Steins;Gate"])

Medium, Genre & Catalog Attributes

types["ANIME", "MANGA", "LIGHT_NOVEL", "VISUAL_NOVEL", "MANHWA", "MANHUA"]
statuses["finished", "releasing", "upcoming", "cancelled", "hiatus"]
genresCanonical genre strings (e.g. ["Action", "Sci-Fi", "Mystery", "Psychological"])
tags / themesThematic tags and narrative tropes (e.g. ["Time Travel", "Cyberpunk", "Space", "Noir", "Post-Apocalyptic"])
studiosAnimation and production studios (e.g. ["ufotable", "Madhouse", "Bones", "Shaft", "White Fox"])
min_year / max_yearInteger release year boundaries (e.g. 1998, 2024)
yearsSpecific release years list (e.g. [1998, 2011])
min_scoreMinimum review score threshold (float: 0.0 to 10.0, e.g. 8.5)
adultExplicit-content boolean (default false excludes 18+ content; true returns only adult works)

The include Relational Parameter

By default, retrieval payloads return canonical metadata and text chunks. Pass the include array in your request to hydrate rich relational sub-trees:

"staff"Attaches key credited creators (directors, series composers, writers) with their production roles.
"characters"Attaches major characters with their canonical names, role tiers (MAIN, SUPPORTING), and assigned voice actors.
"relations"Attaches franchise connections including source adaptations, sequels, prequels, spin-offs, and alternative versions.
