💡 Intended Scope & Relational Depth

Anime Akashic Records (AAR) is purpose-built for semantic retrieval, trope discovery, natural language query resolution, production metadata filtering, and grounded AI answer synthesis across 144,000+ indexed canonical works and 444,000+ interconnected entities (characters, voice actors, directors, authors, composers, and work-to-work relationships). While deep production metadata is fully indexed and filterable in every payload, AAR is not designed as a real-time minute-by-minute episode airing tracker or personal watch-list manager.

Endpoints

Advanced Hybrid Retrieval

The primary discovery endpoint. Blends dense semantic vector embeddings with lexical keyword matching and neural reranking. Returns ranked works paired with confirming excerpts.

Optimal Integration Profiles
Designed specifically for Streaming Platforms (instant ~500ms search bars across character traits & plot memories), AI Chatbots (grounded context blocks with exact character synergy and zero hallucination), and Autonomous AI Agents (fast, deterministic tool calling with strict schema validation).
Architecture & Speed Dual Query Processing Modes: Fast Native vs. LLM Breakdown

AAR is engineered to serve real-time user-facing search and automated agents at maximum velocity:

Default Mode (query_breakdown: false)

Sub-second speed (~500ms). Native hybrid pipeline fusing ScaNN-cascade dense vectors (Qdrant int8), FTS5 BM25, in-memory character synergy aggregation, and deep Cross-Encoder reranking without any LLM delay. Active by default for all requests.

Opt-In LLM Breakdown (query_breakdown: true)

Compound Query Decomposition. Pass "query_breakdown": true in your request body when you want an LLM to decompose complex multi-part comparative queries (e.g. "anime like Cowboy Bebop with themes like Psycho-Pass") into targeted sub-probes before retrieval (adds ~400–800ms).

Request Parameters

questionstring (required) — Natural language question, scene description, trope, or production query.
limitinteger (optional, default: 8, max: 50) — Maximum number of works to return.
modestring (optional, default: "hybrid") — "hybrid" for balanced keywords & concepts; "semantic" for vector-only retrieval.
query_breakdownboolean (optional, default: false) — Default is false for ultra-low-latency native hybrid retrieval (~500ms) without LLM query rewriting delay. Pass true only when you want an LLM to decompose complex multi-part or comparative queries (e.g. "anime like X but with themes like Y") into targeted sub-probes before retrieval (adds ~400–800ms).
nsfwboolean (optional, default: false) — Explicitly marks query as adult/NSFW, skipping LLM query refinement and proceeding directly to vector embedding.
includearray of strings (optional) — Expanded relational payloads to attach to each result: ["staff", "characters", "relations"].
scopeobject (optional) — Hard membership and relational filters (see Scope Filter Fields below).

Question Answering

Conversational endpoint tailored for chatbots and AI agents. Synthesizes a grounded, factual natural-language prose answer derived strictly from retrieved canonical catalog records, production staff, and franchise relations.

Public Free Key Rate Limits: Strictly capped at 1 request/second and 3 requests/minute per IP. For higher ask quotas or unthrottled SLA, contact AnimeAkashicRecords@hotmail.com.
Optimal Integration Profiles
Designed specifically for Streaming Platforms (instant ~500ms search bars across character traits & plot memories), AI Chatbots (grounded context blocks with exact character synergy and zero hallucination), and Autonomous AI Agents (fast, deterministic tool calling with strict schema validation).

Request Parameters

questionstring (required) — Natural language question regarding production, staff, franchise relations, or catalog metadata.
limitinteger (optional, default: 8) — Maximum reference works to retrieve for synthesis.
modestring (optional, default: "hybrid") — "hybrid" or "semantic" retrieval mode.
query_breakdownboolean (optional, default: true) — When true, uses LLM query refinement. When false, embeds the query directly as-is to minimize latency.
nsfwboolean (optional, default: false) — Explicitly marks query as adult/NSFW, skipping LLM query refinement and proceeding directly to vector embedding.
includearray of strings (optional) — Relational payloads to attach: ["staff", "characters", "relations"].
scopeobject (optional) — Hard membership and relational filters (see Scope Filter Fields below).

cURL (GET)

Work-to-Work Semantic Recommendation

Discover titles with matching narrative DNA, emotional tone, and thematic essence to any specified work. Unlike superficial genre checkboxes, this endpoint computes deep vector proximity across plot complexity, character dynamics, and aesthetic pacing.

Optimal Integration Profiles
Designed specifically for Streaming Platforms (instant ~500ms search bars across character traits & plot memories), AI Chatbots (grounded context blocks with exact character synergy and zero hallucination), and Autonomous AI Agents (fast, deterministic tool calling with strict schema validation).

Request Parameters

seed_work_idsarray of strings (required for POST) — 1 to 10 canonical work identifiers (e.g. ["work:anime:mal_9253_al_9253"]).
work_idstring (path parameter for GET) — Canonical work ID (e.g. /recommend/work:anime:mal_9253_al_9253).
target_scopestring (optional) — Restrict recommendations to a medium: "anime", "manga", etc.
limitinteger (optional, default: 10, max: 50) — Number of recommended titles to return.

Example Request (GET)

cURL (GET) 
curl -X GET "https://api.aarecords.tech/recommend/work:anime:mal_9253_al_9253?limit=5"   -H "x-api-key: aar_free_access"

Example Request (POST — JSON Payload)

cURL (POST)

    "seed_work_ids": ["work:anime:mal_9253_al_9253"],

Community Suggestions & Catalog Contributions

Propose brand-new anime, manga, or light novels, suggest custom narrative descriptions, or recommend metadata corrections. Submissions are automatically clustered and aggregated for catalog updates.

🤝 We Actively Welcome Your Contributions Here

Whether proposing missing titles, providing rich narrative plot descriptions, or suggesting corrections to existing works: we actively welcome community and AI agent contributions through this endpoint. All submissions are automatically clustered, deduplicated, and reviewed for inclusion in canonical catalog updates.

Request Parameters (POST /suggest or /contributions)

contribution_typestring (required) — One of "ADD_WORK", "ADD_ALIAS", "EDIT_METADATA", "FEATURE_OR_VIBE".
media_typestring (required) — One of "anime", "manga", "light_novel", "visual_novel", "manhwa", "manhua".
titlestring (required) — Primary or canonical title of the work.
custom_descriptionstring (optional, up to 10,000 characters) — Detailed story synopsis, worldbuilding rules, character motivations, and thematic progression.
aliasesarray of strings (optional) — Alternative titles, Romaji names, or acronyms.
authorstring (optional) — Original author, mangaka, or director.
release_yearinteger (optional) — Release year (e.g. 2024).
tagsarray of strings (optional) — Relevant genres or trope tags.

Example Request (POST /suggest)

cURL (POST) 
curl -X POST "https://api.aarecords.tech/suggest"   -H "Content-Type: application/json"   -H "x-api-key: aar_free_access"   -d '{

Scope Filter Fields

Hard filters supplied under the scope object. Unrecognized fields are strictly rejected with 422 so configuration mistakes are caught immediately. All staff and character filters support canonical romanizations and case-insensitive matching.

Production, Staff & Entity Filters

director_namesList of directors (e.g. ["Shinichirou Watanabe", "Akiyuki Shinbou", "Hideaki Anno"])
author_namesOriginal manga authors, light novel writers, or creators (e.g. ["Nisio Isin", "Kentarou Miura", "Naoki Urasawa"])
composer_namesMusic and soundtrack composers (e.g. ["Yoko Kanno", "Hiroyuki Sawano", "Yuki Kajiura", "Satoru Kousaki"])
voice_actor_namesVoice cast / seiyuu (e.g. ["Hiroshi Kamiya", "Chiwa Saitou", "Mamoru Miyano", "Megumi Hayashibara"])
staff_namesGeneral staff spanning all credited production roles (character designers, scriptwriters, sound directors)
character_namesCanonical characters appearing in the work (e.g. ["Shinobu Oshino", "Rintaro Okabe", "Spike Spiegel"])
titlesFilter directly by specific work titles (e.g. ["Cowboy Bebop", "Steins;Gate"])

Medium, Genre & Catalog Attributes

types["ANIME", "MANGA", "LIGHT_NOVEL", "VISUAL_NOVEL", "MANHWA", "MANHUA"]
statuses["finished", "releasing", "upcoming", "cancelled", "hiatus"]
genresCanonical genre strings (e.g. ["Action", "Sci-Fi", "Mystery", "Psychological"])
tags / themesThematic tags and narrative tropes (e.g. ["Time Travel", "Cyberpunk", "Space", "Noir", "Post-Apocalyptic"])
studiosAnimation and production studios (e.g. ["ufotable", "Madhouse", "Bones", "Shaft", "White Fox"])
min_year / max_yearInteger release year boundaries (e.g. 1998, 2024)
yearsSpecific release years list (e.g. [1998, 2011])
min_scoreMinimum review score threshold (float: 0.0 to 10.0, e.g. 8.5)
adultExplicit-content boolean (default false excludes 18+ content; true returns only adult works)

The include Relational Parameter

By default, retrieval payloads return canonical metadata and text chunks. Pass the include array in your request to hydrate rich relational sub-trees:

"staff"Attaches key credited creators (directors, series composers, writers) with their production roles.
"characters"Attaches major characters with their canonical names, role tiers (MAIN, SUPPORTING), and assigned voice actors.
"relations"Attaches franchise connections including source adaptations, sequels, prequels, spin-offs, and alternative versions.
