💡 Intended Scope & Best Practices

Anime Akashic Records (AAR) is purpose-built for semantic retrieval, trope discovery, natural language query resolution, and grounded AI lore synthesis across 180,000+ works. While canonical metadata (medium type, lifecycle status, release year, genres, and studios) is fully indexed and filterable in every payload, AAR is not designed as a real-time minute-by-minute episode airing tracker or personal watch-list manager.

Endpoints

Advanced Hybrid Retrieval

The primary discovery endpoint. Blends dense semantic vector embeddings with lexical keyword matching and neural reranking. Returns ranked works paired with confirming excerpts.

Request Parameters

questionstring (required) — Natural language question, scene description, trope, or query.
limitinteger (optional, default: 8, max: 50) — Maximum number of works to return.
modestring (optional, default: "hybrid") — "hybrid" for balanced keywords & concepts; "semantic" for vector-only retrieval.
scopeobject (optional) — Hard membership filters (types, statuses, genres, tags, studios, min_year, max_year).

Example Request

cURL 
curl -X POST "https://anime-akashic-records-aar-api.p.rapidapi.com/search" \
  -H "Content-Type: application/json" \
  -H "X-RapidAPI-Host: anime-akashic-records-aar-api.p.rapidapi.com" \
  -H "X-RapidAPI-Key: YOUR_RAPIDAPI_KEY" \
  -d '{
    "question": "Time-travel visual novel with branching timelines",
    "limit": 8,
    "mode": "hybrid",
    "scope": {
      "types": ["VISUAL_NOVEL"]
    }
  }'

Question Answering & Lore Synthesis

Conversational endpoint tailored for chatbots, AI agents, and lore inquiries. Returns a synthesized, factual natural-language prose answer grounded in retrieved corpus citations, along with ranked supporting works.

Request Parameters

questionstring (required) — Specific lore inquiry, character dynamic question, or relationship comparison.
limitinteger (optional, default: 8) — Maximum reference works to retrieve for synthesis.
scopeobject (optional) — Filter candidates by medium (types) or genre.

Example Request

Scope Filter Fields

Hard filters supplied under the scope object. Unrecognized fields are strictly rejected with 422 so configuration mistakes are caught immediately.

types["ANIME", "MANGA", "LIGHT_NOVEL", "VISUAL_NOVEL", "MANHWA", "MANHUA"]
statuses["finished", "releasing", "upcoming", "cancelled", "hiatus"]
genresList of genre strings (e.g. ["Action", "Sci-Fi", "Mystery"])
tagsThematic tags (e.g. ["Time Travel", "Cyberpunk", "Post-Apocalyptic"])
studiosStudio names or substrings (e.g. ["ufotable", "Madhouse"])
min_year / max_yearInteger release year boundaries (e.g. 2010, 2024)
min_scoreMinimum review score threshold (float)
adultExplicit-content boolean; default excludes 18+ content
